# CS-510-Project-3
The GitHub repository for Project 3 of CS510
This is a project for CS 510 Programming Lang Concepts.
The Project is to build a simple web app that draws Abstract Syntax Trees (AST). The language to be parsed and displayed is `MicroML`. The language parser should be able to handle at least functions and preferably higher order functions.

Project Requirements:
- A web app (using dotnet) is required for this project. Abstract Syntax Trees (AST) should be displayed on a web page.
- The web app should be able to parse the `MicroML` code.
- Use CSS to style the web page.
- The app is a single page web app. It should be able to take input from the user and display the AST on the same page.
